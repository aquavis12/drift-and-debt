# drift-and-debt

A small polyglot codebase simulating years of unattended engineering drift —
built as a demo fixture for AWS Transform continuous modernization.

Three services, three languages, one shared history of "we'll fix it later":

- `lambda-python/` — a cost reporting Lambda
- `node-service/` — an internal reporting proxy
- `java-module/` — a reporting utility class

None of this is production code. It exists to be analyzed, not deployed.
